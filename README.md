# 🤖 Bot-Like Behaviour Detection in Social Media Networks

An end-to-end **Social and Multimedia Analytics** project for detecting bot-like behaviour in social media networks using behavioural analysis, machine learning, NLP, and social network analysis.

---

## 📌 Project Overview

Social media platforms contain both genuine users and automated accounts (bots).

This project analyzes publicly available social media data to identify accounts that exhibit **bot-like behavioural patterns**.

The system combines:

- 📊 Data preprocessing and exploratory analysis
- 🔎 Behavioural feature analysis
- 🤖 Machine learning-based bot detection
- 📝 NLP and text analysis
- 🕸️ Social network analysis
- 📈 Interactive analytics dashboard
- 👤 Individual account investigation

> **Note:** The system provides model-based predictions and probabilities. A prediction does not prove that an account is actually a bot.

---

## 🎯 Objectives

- Analyze social media user behaviour
- Identify patterns associated with bot-like accounts
- Engineer meaningful behavioural features
- Apply machine learning classification
- Analyze social network relationships
- Perform NLP analysis when text data is available
- Visualize analytical results
- Provide account-level bot probability
- Compare different machine learning models
