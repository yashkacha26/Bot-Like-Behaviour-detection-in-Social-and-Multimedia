1. PROBLEM STATEMENT
================================================================================

1.1 BACKGROUND & CONTEXT:
The explosion of social networking services (SNS) has transformed online 
communication, information dissemination, and commerce. However, this ecosystem 
is under continuous threat from coordinated inauthentic behaviour, automated bot 
networks, sybil accounts, and malicious astroturfing campaigns. Sophisticated bot 
operators deploy armies of automated entities designed to manipulate public 
opinion, distort political discourse, artificially amplify financial assets 
(e.g., cryptocurrency pump-and-dump schemes), execute spam campaigns, and seed 
hyper-targeted disinformation.

1.2 THE CORE CHALLENGE:
Early automated bots were rudimentary—exhibiting extreme posting frequencies, 
empty bio descriptions, and erratic following patterns. In contrast, modern 
adversaries utilize advanced evasion techniques:
  - Behavioral Mimicry: Automated schedulers that emulate circadian human sleep/wake 
    cycles and introduce random burstiness intervals.
  - Profile Obfuscation: Harvesting legitimate user avatars, borrowing real biographical 
    text, and maintaining plausible follower-to-following ratios.
  - Multimodal Coordinated Attacks: Adversaries no longer rely solely on text. Campaigns 
    employ coordinated video mirrors, cloned profile banners, watermarked memes, 
    synthetic voice tracks, and template replication to overwhelm traditional 
    text-only filters.
  - Network Concealment: Dense internal follower rings (follow-back syndicates) designed 
    to inflate PageRank and graph centrality without triggering crude threshold filters.

1.3 THE OBJECTIVE OF SMA SENTINEL:
The primary objective of this project is to construct an end-to-end, multi-layered 
intelligence platform that detects, profiles, visualizes, and triages bot-like 
inauthentic behaviour across all social media dimensions:
  1. Profile & Behavioral Telemetry: Temporal dynamics, posting velocity, follow ratios, 
     and composite suspicion indices.
  2. Natural Language Processing (NLP): VADER emotion/compound polarity analysis and 
     TF-IDF token discrimination.
  3. Graph Topology: Social interaction follower graphs, in/out-degree distribution, 
     and PageRank global influence ranking.
  4. Machine Learning Classification: 5-fold cross-validated classifiers (Random Forest, 
     Decision Trees, Logistic Regression) evaluated on hold-out test sets.
  5. Multimedia & Computer Vision Surveillance: YOLOv8 object localization, DeepSORT 
     Kalman trajectory tracking, Content-Based Image Retrieval (CBIR) via FAISS vector 
     indexing, and video temporal keyframe shot-boundary decomposition.
  6. Forensic Investigation Dossier: Interactive drill-down triage allowing security 
     analysts to inspect specific entities, compare them against population norms, 
     and export forensic JSON/CSV dossiers.

2. TECHNOLOGY STACK
================================================================================

2.1 FRONTEND ARCHITECTURE:
  - Framework: React 19 + Vite 8
  - Language: Modern ECMAScript (ES2023+ JSX)
  - Styling System: Custom Vanilla CSS Design System (`index.css`)
    * Obsidian & Slate Security Palette (#090d16 canvas, #0f172a surface, #1e293b hairline borders)
    * Modern Typography: 'Inter' (headings/body) and 'JetBrains Mono' (numerical telemetry, hashes, IDs)
    * Glassmorphism & Micro-Interactions: Backdrop blur, responsive CSS grid layouts, smooth transitions
    * Zero Emojis: Strictly professional SVG cybersecurity iconography via Lucide React
  - Data Visualization: Recharts (ResponsiveContainer, BarChart, PieChart, AreaChart, RadarChart, ScatterChart, LineChart)
  - Iconography: Lucide React (Shield, Activity, Database, Eye, Image, Video, Cpu, Network, Search, etc.)
  - HTTP Communication: Axios configured with `/api` proxy in `vite.config.js` to ensure zero IPv6/IPv4 binding discrepancies

2.2 BACKEND & API ARCHITECTURE:
  - Runtime: Python 3.11
  - Web Framework: FastAPI (Asynchronous high-performance ASGI framework)
  - Web Server: Uvicorn ASGI Server binding to `127.0.0.1:8000`
  - Relational Database: SQLite3 (`bot_detection.db`) with relational tables:
    * `accounts`: Flattened metadata, follower counts, verified flags, account age
    * `features`: Engineered behavioral indicators, ratios, scores, labels
    * `network_nodes` & `network_edges`: Graph topology nodes and directed edges
    * `system_health`: Telemetry status, uptime metrics, and API build versioning

2.3 DATA PROCESSING & FEATURE ENGINEERING:
  - Data Manipulation: Pandas & NumPy
  - Benchmark Corpus: TwiBot-20 (academic benchmark dataset of annotated Twitter/X accounts)
  - Feature Dimensions: 14 primary engineered features:
    * `followers_count`, `friends_count`, `statuses_count`, `favourites_count`, `listed_count`
    * `followers_following_ratio` (ff_ratio)
    * `tweets_per_day`, `favourites_per_day`
    * `account_age_days`, `description_length`
    * `verified`, `default_profile`, `default_profile_image`, `geo_enabled`
    * Composite Indices: `suspicion_score` (0-100) and `activity_score` (0-100)

2.4 MACHINE LEARNING & STATISTICAL SUITE:
  - ML Library: Scikit-Learn
  - Architectures Implemented:
    * Random Forest Classifier (Leading Architecture: 89.2% Accuracy, 0.941 ROC-AUC)
    * Decision Tree Classifier (Interpretable tree splits, 84.1% Accuracy)
    * Logistic Regression (L2 regularized linear baseline, 81.2% Accuracy)
  - Validation Pipeline: 5-Fold Stratified Cross-Validation on training splits + 20% hold-out evaluation
  - Metrics Tracked: Accuracy, Precision, Recall, F1 Score, ROC-AUC, Confusion Matrix, Gini Feature Importances

2.5 NATURAL LANGUAGE PROCESSING (NLP):
  - Sentiment Analysis: NLTK VADER (Valence Aware Dictionary and sEntiment Reasoner)
    * Compound polarity scores (-1.0 to +1.0)
    * Valence breakdown (Positive, Neutral, Negative proportions)
  - Lexical Discrimination: Scikit-Learn `TfidfVectorizer` (Unigrams, sublinear term frequency, top 25 discriminators)
  - Word Frequency Profiling: Unigram frequency counter with stopword filtering

2.6 NETWORK & GRAPH TOPOLOGY ANALYTICS:
  - Graph Engine: NetworkX
  - Graph Type: Directed Graph (DiGraph) modeling follower and following relationships
  - Metrics Computed:
    * Node Degree, In-Degree (Popularity/Authority), Out-Degree (Hub/Broadcaster)
    * Network Density
    * PageRank Centrality (Random walk stationary distribution with damping factor alpha = 0.85)

2.7 MULTIMEDIA FORENSICS & COMPUTER VISION:
  - Object Localization: YOLOv8 (You Only Look Once v8x architecture)
  - Spatial Tracking: DeepSORT (Kalman Filtering + Hungarian matching)
  - Visual Clone Search (CBIR): Content-Based Image Retrieval via FAISS (Facebook AI Similarity Search) IVF-Flat index
  - Perceptual Hashing: 64-bit DCT perceptual hash (pHash) for image variant and clone detection
  - Video Temporal Segmentation: Inter-frame color histogram Euclidean difference scoring for shot boundary detection

4.1 FEATURE NORMALIZATION & DERIVATION:
  - Followers-to-Following Ratio (FF Ratio):
      FF_Ratio = followers_count / max(friends_count, 1)
  - Posting Velocity:
      Tweets_Per_Day = statuses_count / max(account_age_days, 1)
  - Account Age (Days):
      Account_Age = (Current_Time_UTC - created_at_UTC).days

4.2 COMPOSITE BOT SUSPICION INDEX (Heuristic Risk Engine):
  The heuristic suspicion index S in [0, 100] is calculated as:
      S = min(100, Sum(w_i * Flag_i))
  Where weights w_i are assigned based on known bot characteristics:
    * Default Profile Avatar: +25
    * Follower Imbalance (Following > 500 & Followers < 20): +20
    * High Posting Velocity (> 50 tweets/day): +20
    * Unverified Account: +10
    * Empty Description Bio (Length == 0): +15
    * High Following Velocity (> 30 follows/day): +10

4.3 VADER SENTIMENT POLARITY (Linguistic Engine):
  The normalized compound sentiment score c in [-1.0, 1.0] is computed from valence sums:
      x = Sum(v_i)
      c = x / sqrt(x^2 + alpha)
  Where alpha is a normalisation constant (typically alpha = 15).
  Valence scores v_i incorporate punctuation boosters, capitalization, and negation rules.

4.4 TF-IDF LEXICAL DISCRIMINATION:
  Term Frequency - Inverse Document Frequency weight for token t in document d across corpus D:
      TF-IDF(t, d, D) = TF(t, d) * log( (1 + |D|) / (1 + DF(t, D)) ) + 1
  Sublinear term frequency scaling is applied:
      TF(t, d) = 1 + log(count(t, d)) for count > 0

4.5 PAGERANK GRAPH CENTRALITY:
  The stationary probability vector p over directed follower graph G = (V, E) satisfies:
      p = ( (1 - d) / |V| ) * e + d * M * p
  Where:
    * d = 0.85 (damping factor)
    * M is the column-stochastic transition matrix: M_ij = 1 / out_degree(j) if (j, i) in E
    * e is the unit column vector

4.6 FAISS COSINE SIMILARITY (Visual Embeddings):
  For query image vector q and gallery embedding g in R^d:
      Cosine_Similarity(q, g) = (q . g) / ( ||q||_2 * ||g||_2 )
  FAISS normalizes vectors to unit length so that inner product equals cosine similarity:
      Similarity = <q_norm, g_norm>

4.7 SHOT BOUNDARY DETECTION (Video Segmentation):
  Color histogram difference between consecutive frames F_t and F_{t+1}:
      Diff(F_t, F_{t+1}) = Sum_b | H_t(b) - H_{t+1}(b) | / (2 * N)
  Where H(b) is bin b of the normalized RGB/HSV histogram and N is total pixel count.
  A transition is flagged when Diff exceeds threshold theta (default 0.70).
